## 🚀 Flagship Work
*(client systems, described without client names)*

- **Maintenance Triage Agent** (LangGraph · FastAPI · Postgres · MCP): resolves **60–85%** of requests end to end. Human time per ticket went from **4h to 12m**.
- **Agent Eval Harness** (Langfuse · DeepEval · CI): **14 graders** gate every merge. LLM judges agree with human labels at **95% TPR / 93% TNR**.
- **RAG Retrieval** (Qdrant · OpenAI embeddings): Recall@5 went from **18% to 87%** on a golden set built from real user questions.
- **Model Selection** (LiteLLM gateway): **15x lower** cost per correct answer across 5 models. Also caught a spend loop that would have cost **100x** more.
- **Semantic Caching** (Redis · FastAPI): P95 time to first token dropped from **3.2s to 1.3s** on repeat queries.

## 🧠 How I Work
Before I write any code, I agree with the team on what a good answer looks like. Then I measure every change against it, offline first, then on live traffic. Seven years of backend and cloud work means I also care about retries, cost, permissions, and what happens when things break.
